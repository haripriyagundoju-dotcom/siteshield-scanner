# SiteShield Scanner

Build a web security scanner dashboard in React with Tailwind. Pages: Landing page, Login/Signup, Dashboard with a URL input and “Scan” button, Results page showing a security grade (A to F), a list of passed and failed checks with fix suggestions, and a Scan History page. Use Supabase for auth and a scans table with row-level security so users see only their own scans. Use a dark cybersecurity theme.You’re building a website that checks other websites for security weaknesses. It’s like a health check-up, but for a website’s security.

A user types in a website address (for example, their own site), clicks “Scan”, and your tool checks it and shows a grade from A to F, with a list of what’s wrong and how to fix it.
